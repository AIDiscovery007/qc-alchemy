# QC-Reframe v0.1.19 · 并行任务与共享图片存储

- 支持跨图片、项目、路径和提示词版本并行逆向、生图，进度与取消各自独立；同一提示词版本仍限制同时一次生图。
- 「完整复刻」生图只发送提示词与排除项，不再附参考图；已有提示词无需重新逆向即可使用。
- 「提取风格」和「主体重演」生图使用当前路径最后上传、表单实际显示的主体图。换主体无需重新逆向，每次生图保留当时输入，历史结果不变。
- 三条路径均支持编辑中文、英文提示词和排除项。保存后用于复制、导出和后续生图，已经提交的生图保留原输入。
- 参考图、主体图与生成结果按图片内容共享存储，同一内容只保存一次。删除项目时，仅回收没有其他引用的图片；任务执行期间延后回收。
- 普通运行文件按配置、记录、图片、日志和临时状态收纳到 `.local/config/`、`records/`、`images/`、`logs/`、`runtime/`。日志达到 5 MB 时在下次启动轮替，只保留当前日志与上一份。

## 安装与升级

首次安装使用 [README 中的安装 Prompt](https://github.com/AIDiscovery007/qc-reframe/tree/v0.1.19#让-codex-帮你安装)。需要完整仓库中的本机服务和技能；附件 Chrome ZIP 仅包含浏览器端。

已有用户：完成或取消任务 → 在原目录 `npm stop` → 备份整个 `.local/` → 获取 v0.1.19 → `npm run setup` → `npm start` → 重新加载原扩展并刷新网页。请同时更新本机服务和浏览器扩展。

首次启动自动迁移旧配置、记录和图片，保留配对码、模型选择、提示词和图片内容，无需重新配对。图片先校验并保存共享引用，再清理旧副本；迁移中断可重启继续，同名冲突保留文件并停止迁移，损坏记录阻止自动图片清理。开发测试文件、手动导出、用户上传原件和 Codex 原始生成目录不自动整理。

迁移后图片的本机路径可能改变，请在结果面板重新复制。新存储格式需使用新版服务；如需回退，应使用升级前的完整数据备份。相同画面经重新压缩、裁剪或格式转换后，可能被视为不同图片。

## 验证与限制

发布 ZIP 构建、TypeScript 检查及 81 项自动测试通过。测试覆盖并行与独立取消、纯文生图输入、最新主体与历史快照、提示词编辑持久化、共享图片与删除回收、新旧安装迁移、冲突保护及路径隔离。ZIP 仅包含浏览器端文件，不含本地项目、图片、令牌或配置。

开发期间已通过浏览器预览验证并行操作和提示词编辑；已有本地数据先在临时副本验证，再于服务空闲时迁移，文件内容校验一致，迁移后通过服务接口读取项目与图片。

本次未调用真实逆向或生图模型；换主体上传流程尚未完成界面端到端验证。自动测试和预览不代表已安装扩展、账号并发吞吐量或生图速度的实测。任务期间不能切换模型；模型验证期间暂不能提交新任务。
