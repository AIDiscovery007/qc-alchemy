# QC-Reframe v0.1.23 · 精简界面说明

2026-10-01 · 全局清理重复解释功能的辅助文案，让界面更专注于创作。

## 本次变化

- 图片标题只保留「图 1 · 主体」「图 2 · 参考」等角色标签，去掉「保留身份与结构」「重演画面」「提取视觉语言」。
- 旋转工具栏移除「应用后用于后续逆向与生图」，保留旋转、应用操作和异常提示。
- 工作台、轻量面板、项目库、任务中心、新建项目和设置页同步精简重复说明、副标题与页脚，并收紧空白。
- 保留表单标签、必要操作条件、错误、进度、版本、图片尺寸、模型信息和删除后果；任务指令与提示词内容不受影响。

## 升级

从 v0.1.21 / v0.1.22 升级：更新并重新加载原扩展，再刷新工作台与网页。本次无服务逻辑、权限或数据格式变化，无需迁移项目、图片或配对信息；现有服务可继续使用。通过源码更新且希望服务版本号同步时，待任务结束后重启服务。

更早版本按各版本说明同步更新本机服务。首次安装请使用 [安装指引](https://github.com/AIDiscovery007/qc-reframe/blob/v0.1.23/browser-extension/docs/INSTALL_WITH_CODEX.md)。Chrome ZIP 仅包含浏览器端，仍需完整仓库中的本机服务和技能。
