# QC-Reframe v0.2.0 · 画布工作台与轻量创作入口

2026-10-03 · 工作台、工具栏弹窗和网页悬浮面板统一创作体验，从快捷操作接续到完整编辑。

## 工作台：画布、图条与提示词面板

- **稳定的图片展示区**：采用画布与图条布局，图片完整适应容器，横竖图切换不再带动页面高度变化。删除步骤标题与空提示词占位，减少重复说明。
- **图条下方集中操作**：悬浮工具栏容纳四种逆向模式、参考/主体替换、互换、移除、多图设置、提示词版本与面板开合；各路径和版本保留独立输入状态。
- **可拖拽的提示词面板**：没有提示词时隐藏，逆向成功后展开；300ms上滑、横条拖动跟手、向上越界增加阻力，下拉超过60px或有效轻甩收起，未达到条件时约420ms回弹。取消拖拽恢复打开；键盘和减少动态效果即时响应，关闭返回触发器焦点。
- **完整能力继续保留**：提示词中英文、复制、Markdown导出、编辑与排除项，以及目标尺寸、生图、结果历史和对照均可用。版本选择始终可达；编辑草稿或任务输入变化时保留生成限制，避免使用过期提示词。
- **图片放大入口统一**：输入图、多图编排/组合、生成结果与对照图均在实际图片右下角显示34px放大按钮，随图片比例和窗口更新位置；沿用缩放、平移、可编辑输入旋转及关闭后焦点恢复。修复参考图读取失败后无法通过新上传恢复的问题。

## 两个轻量入口：保留快捷闭环

- 工具栏弹窗和网页悬浮面板共用紧凑画布、图条与工具栏，保留参考/主体上传、互换、移除、四模式和版本切换、任务指令、逆向进度与取消、提示词语言和复制。
- 可直接生成图片、取消生图和查看当前结果；沿用当前提示词版本最近一次生图的目标比例，无记录时使用自动。指定尺寸、完整编辑、多图编排、历史对照、项目管理及高级设置在工作台完成。
- 打开工作台准确携带来源项目、模式、实际显示版本（含新版本状态）与未提交草稿，避免被其他页面的全局选图覆盖。弹窗与不同网页标签的草稿分开保存；大草稿交接不再重复占用两份空间，读取和一次性消费按序执行，容量或开页失败保留恢复路径。
- 修复上传中切换上下文后忙碌状态不释放，以及主体上传失败时可能沿用旧图的问题。缺图、通用风格、占位符、未保存编辑和运行中的任务继续阻止无效或重复生图。

## 提示词：人物细节与整体氛围

四条逆向路径加强可见人物的微表情、视线、神态和微动作观察，并在中英文提示词正文中保留独立段落。按完整复刻、风格转换、主体重演和多图分工确定来源，用户明确保留项优先；不补造遮挡或无法辨认的细节，无人画面省略人物专段。

另新增独立的「整体情绪与氛围」段落，覆盖人物、静物和无人画面，将感受、强弱、层次与可见光色、构图、环境和画法联系起来。仅换画法时保持主体结构与表现，不为迁移情绪改变锁定内容。新规则需更新服务并重新逆向；不改写历史记录，也不承诺复刻率提升。

## 升级与安装

从 v0.1.26 升级无需数据迁移或重新配对，依赖版本未变，现有项目、提示词、图片和配置保留。本次同时包含 bridge 与运行 skill 更新，请更新完整仓库：

1. 等待运行中的任务结束，或在界面取消后，在原 `browser-extension` 目录执行 `npm stop`。
2. 保留本地改动与 `.local/`，将原仓库更新到 `v0.2.0`，执行 `npm run setup`，再执行 `npm start`。健康检查应显示服务版本 `0.2.0`。
3. 重新加载原浏览器扩展；ZIP 安装使用本次 Chrome ZIP，扩展管理页确认 `0.2.0`。刷新已打开的工作台和网页，使新内容脚本生效。
4. 需要新版人物与氛围规则时重新逆向。已有提示词继续保持原样；轻量草稿仅保存在浏览器会话中，不承诺跨浏览器重启保留，重要编辑请先保存。

首次安装按 [v0.2.0 安装指引](https://github.com/AIDiscovery007/qc-reframe/blob/v0.2.0/browser-extension/docs/INSTALL_WITH_CODEX.md) 获取完整仓库。**Chrome ZIP 仅含浏览器端，不含本机 bridge 和运行 skill，不能单独完成首次安装。**
