# QC-Reframe v0.1.22 · 清爽界面与结果切换

2026-10-01 · 在现有布局上减少装饰，让图片与创作内容更突出。

## 更轻的界面

- 工作台、项目库、网页浮层、设置与图片预览减少重复描边和分割线，移除硬阴影与画布网点。
- 用暖白底色、浅色分区和留白建立层次；保留亮黄主操作、四条路径选中色及错误提示。
- 浮层采用柔和阴影，表单与图片选中状态保留必要的边界。

![v0.1.22 工作台：暖白底色与浅色分区](https://raw.githubusercontent.com/AIDiscovery007/qc-reframe/v0.1.22/browser-extension/docs/releases/v0.1.22-workspace.jpg)

## 缩略图只切换结果

工作台结果区底部的生成记录缩略图点击后只切换当前结果，不再弹出放大预览。上方结果大图仍可点击放大；项目、任务和输入图片的预览行为保留。

## 升级

从 v0.1.21 升级：更新扩展后，重新加载原扩展并刷新工作台与网页。本次无服务逻辑、权限或数据格式变化，无需迁移项目、图片与配对信息；运行中的 v0.1.21 服务可继续使用。通过源码更新且希望服务版本号同步时，待任务结束后重启服务。

更早版本按各版本说明同步更新本机服务。首次安装请使用 [安装指引](https://github.com/AIDiscovery007/qc-reframe/blob/v0.1.22/browser-extension/docs/INSTALL_WITH_CODEX.md)。Chrome ZIP 仅包含浏览器端，仍需完整仓库中的本机服务和技能。
