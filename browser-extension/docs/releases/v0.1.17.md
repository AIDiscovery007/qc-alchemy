# QC Alchemy v0.1.17 · 独立模型选择

- 新增「连接设置 → 插件模型」：从本机 Codex 获取模型列表，支持刷新及「验证并使用」。
- 验证成功后保存为插件专用模型，逆向与生图使用该选择，不修改 Codex 全局设置。
- 区分待验证、已验证和不可用；切换验证失败保留原选择，账号或提供方变化后需重新验证。

<img src="https://raw.githubusercontent.com/AIDiscovery007/qc-alchemy/v0.1.17/browser-extension/docs/releases/v0.1.17-model-picker.png" width="420" alt="QC Alchemy 0.1.17 用户实机截图：插件模型下拉列表" />

**请先把本机 Codex CLI（独立命令行程序）更新到最新版本。** 更新桌面 App 不代表插件调用的 CLI 已更新；旧 CLI 可能无法列出 GPT-6.1 Sol、GPT-6 Astra、GPT-6 Sol 等新模型。更新后重启本机服务，再点「刷新列表」。具体模型以账号权限和验证结果为准。[官方 CLI 更新说明](https://learn.chatgpt.com/docs/codex/cli)

## 安装与升级

首次安装使用 [README 中的安装 Prompt](https://github.com/AIDiscovery007/qc-alchemy/tree/v0.1.17#让-codex-帮你安装)。需要完整仓库中的本机服务；附件 Chrome ZIP 仅包含浏览器端。

已有用户：完成或取消任务 → `npm stop` → 获取 v0.1.17 → `npm run setup` → `npm start` → 重新加载扩展并刷新网页 → 选择模型、验证并使用。若指定过 `CODEX_BIN`，请确认它指向更新后的 CLI。项目记录与配对码保留。

## 验证

类型检查、生产构建和 60 项测试通过；已通过真实本机账号的模型验证与单图提示词逆向。生图能力和额度仍以实际调用结果为准。
