# 待发布：项目分页与按需加载

- 比例选择下方不显示常驻说明；仅在自定义宽高无效时显示校验提示。
- 全局移除用户操作聚焦后的额外描边，覆盖浮层、弹窗、工作台和网页选图按钮；保留常规边框、选中/错误状态与键盘操作。本项无需重启本机服务。
- 轻量浮层与工具栏弹窗移除“视觉观察、排除项、观察边界”三个折叠区；仍可编辑排除项，记录和 Markdown 导出保留完整分析。本项只需重新加载扩展并刷新网页，无需重启服务。
- 生图新增预设与自定义宽高比例，默认自动；通过提示词约束画布比例，每次生图保存比例和完整提示词快照，不修改逆向结果。结果仅显示像素尺寸与实际宽高比（如 `1849 × 851 px · ≈2.17:1`）；旧记录兼容。此项需任务结束后重启本机服务，再重新加载扩展、刷新网页。输入数值代表宽高比例，不是目标像素，不保证模型严格执行，也不裁剪或拉伸结果。
- 项目库每页 24 个，服务端搜索全部标题和来源，侧栏最近 12 个。返回列表保留本次界面的页码与搜索条件；选择本页、删除后页码修正、加载错误重试沿用现有管理流程。
- 卡片直接读取封面缩略图，不再额外获取完整项目历史。侧栏、任务中心和历史生图预览同样使用最长边 480px 的 WebP 缩略图；详情保留完整图片。
- 本机服务缓存项目摘要并维护项目任务索引；列表与项目版本号变化才重新读取，未变化的详情仅返回版本确认。有任务时约 2 秒检查、空闲约 10 秒；隐藏界面暂停轮询，恢复时立即检查。
- 翻页与搜索不增加过场动画，真实加载保留稳定文字反馈；指针按压使用约 120ms 反馈，键盘与减少动态效果路径即时响应。

更新后先运行 `npm install` 安装新增的 `sharp` 依赖，再在任务结束后重启服务、重新加载原扩展目录并刷新页面。缩略图缓存位于 `.local/cache/thumbnails/v1/`，首次读取时按需生成，不修改项目原图、生成图片或配对设置。旧扩展读取不带分页参数的项目接口仍兼容。

服务启动仍会读取所有任务元数据，本次没有引入数据库。分页限制界面与传输负担，不承诺无限量历史的启动性能。
