# 未发布：并行任务、生图输入、提示词编辑与图片去重

风格转换和主体重演在生图时使用当前路径最后上传、表单中实际显示的主体图，换主体后无需再次逆向提示词。图片读取中或上传失败时暂不能生图，避免回退旧主体。每项生图固定保存主体图片引用，保留原提示词、逆向原图和旧结果；重新打开记录时恢复最近生图主体。仅上传而尚未提交的图片仍是界面草稿。

「完整复刻」在逆向阶段使用参考图，生图阶段只发送选定语言的提示词与排除项，不再读取或附加参考图。已保存的提示词可以直接使用此流程，无需重新逆向；参考图文件缺失也不阻止文生图。风格转换与主体重演继续附带主体图与参考图。

不同图片、项目、路径和提示词版本可以同时执行逆向或生图。新选图不再因上一张图片正在逆向而报错，切换项目和关闭浮层后，原任务继续在后台运行。

每项任务使用独立 Codex 进程、进度和取消信号；一个任务失败或取消不影响其他任务。相同提示词版本仍限制同时一次生图，避免重复点击。任务执行期间继续保护模型切换、停止服务和忙碌项目删除；模型验证期间暂不接受新任务。

任务与项目元数据按序原子保存；图片存储会自动迁移，保留原有项目、提示词和图片内容，无需重新配对。

应用本地更新需在任务结束后重启本机服务，重新加载原扩展并刷新已打开的网页。此变更尚未发布，0.1.18 下载包仍使用原来的串行行为。

此前的并行与提示词编辑改动通过构建、TypeScript 检查及 67 项自动测试。隔离的模拟任务覆盖并行逆向、逆向与生图混合执行、多个提示词版本同时生图、独立取消与失败、记录持久化及选新图。

完整复刻的回归用例检查生图输入只有文字和技能、保留提示词与排除项、原图缺失仍可生图，以及双图路径仍传入原图并保留缺图报错。

换主体回归用例覆盖两条双图路径的新图字节、无重新逆向、非法图片拒绝、旧主体缺失时使用新上传图片、旧快照保留、重启恢复与项目删除清理。

换主体功能完成时浏览器控制不可用，未做该上传流程的界面端到端验证或真实生图测试。

浏览器预览确认：逆向中可切换路径提交另一项逆向；已完成提示词可在其他路径逆向时发起生图；生图中可重新逆向；可进入其他项目继续提交，忙碌项目仍不能删除。预览未调用真实模型，也不能代替已安装扩展或账号吞吐量、生图速度的实测。

三条路径的结果区新增「编辑提示词」，可独立修改中文、英文和排除项。保存后复制、导出及后续生图使用修改内容，保留已提交生图快照和其他版本。编辑期间暂停生图与导出，支持取消和空值校验；草稿在当前面板切换语言、路径与版本时保留。

提示词编辑回归覆盖三条路径的保存、重启恢复、版本隔离、生图中编辑保留原输入、后续英文生成以及受限消息认证和字段校验。浏览器预览验证编辑、语言切换、保存、取消、空值禁用及复制反馈；未调用真实模型。

参考图、主体图和生成结果改为按文件内容 SHA256 统一保存到 `.local/images/`，多个项目和任务共享同一文件。生图记录保留当时的主体引用，换图不修改历史。首次启动自动迁移旧记录：先校验共享图片并原子提交引用，再删除旧副本；可在中断后继续，损坏记录保留图片并阻止清理。删除项目后，仅在没有任何引用且所有图片任务结束时回收共享文件。

图片的本机路径会改变，旧的“复制图片路径”需从结果面板重新获取；迁移后使用更新后的本机服务，不直接回退旧版读取新存储格式。此更新不整理仓库根目录的历史 `output/` 或 Codex 原始生成目录。

图片存储更新通过构建、TypeScript 检查和 76 项自动测试，覆盖完整复刻后主体重演只落盘 4 张不同图片、跨项目/角色共享、最后引用删除、并行任务期间延后回收、并发写入、历史迁移重试、损坏记录保留和路径隔离。已有本地数据先在临时副本验证，再在服务空闲时迁移；迁移前后记录及图片内容哈希一致，参考图、主体图和生成结果通过服务接口读取验证。未调用真实逆向或生图模型。

普通安装的运行文件改为统一收纳：配置与配对码进入 `.local/config/`，项目和任务 JSON 进入 `records/`，共享图片仍在 `images/`，服务日志进入 `logs/`，启动锁进入 `runtime/`。旧目录在服务停止后的首次启动自动迁移；管理命令在旧服务运行期间继续读取旧配置。迁移中断可恢复，同名内容冲突保留双方，不搬动开发、测试或用户手动保存的文件。超过 5 MB 的服务日志在下次启动轮替，保留当前日志和上一份。备份整个数据目录即可保留项目、配对与配置。

运行目录整理通过构建、TypeScript 检查及 81 项自动测试，覆盖新安装、旧服务控制与重启升级、配对/模型配置保留、文件迁移中断恢复、同名冲突保护、路径隔离及日志轮替。已有数据先在临时副本验证，再于服务空闲时迁移；文件内容和图片路径保持一致，迁移后项目、任务与结果通过服务接口读取验证。未调用真实模型。
