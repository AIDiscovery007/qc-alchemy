# 待发布

截至 v0.2.0 的阶段改动已整理至 [v0.2.0 版本说明](v0.2.0.md)。

- 图片入口菜单展开后，移到另一张图片立即收起旧菜单，仅显示新图的 R 按钮；保留同图操作、键盘焦点和减少动态效果支持。

- 新增逆向与生图完成提醒：默认未读标记、扩展徽标和静默桌面通知；设置中心可主动开启短提示音并选择音色、音量、试听。并行完成合并提醒，当前可见结果自动已读，取消与历史加载静默；通知支持定位具体结果。
- 后台从鉴权任务状态接口同步已持久化结果，支持关掉面板、后台重启与断线恢复；隐藏项目不弹出或发声，系统通知关闭时保留界面提醒。新增 notifications / offscreen / alarms 权限，更新后需重启本机服务并重新加载扩展。

- 精简隐藏项目流程：文字开关「包含隐藏项目」统一查看范围，卡片、列表和详情可直接隐藏/恢复；批量管理时才显示勾选和批量按钮，成功可撤销，失败保留选择以便重试。撤销仅包含服务端本次实际变更的项目，重复/并发请求不产生错误撤销；范围切换的旧响应不覆盖新打开的项目。需同步更新并重启 bridge，旧服务仍返回请求 ID，不能提供本次跨窗口撤销修复。
