参照 qc-motion-design 案例中的「优化已有」提示词，统一轻量面板与工作台的按钮、对话框、复制和异步反馈，沿用原有布局、业务状态、液态菜单和生图画布。

- 指针按压使用 120ms 的轻缩放；主要按钮沿硬阴影方向下压，网页入口只压缩图标，点击区域和液态表面不动。禁用控件无按压运动。
- 设置、任务中心、新建项目、图片预览、生成信息与删除确认窗口使用 200ms 短入场，原点靠近触发器；关闭即时执行，恢复当前 Document / ShadowRoot 内仍可见的触发器焦点。删除完成后不会覆盖项目列表的焦点。
- 复制成功在原位显示勾号和成功色，图片路径按钮同时显示「已复制路径」，保持尺寸；工作台提示词复制增加可读状态。主体换图时显示真实读取状态。
- 异步状态、错误和展开内容只作 160ms 淡入；CSS starting-style 只在进入时生效，切换输入方式不会重播。路径、语言、搜索、分页和键盘操作即时完成。系统减少动态效果和不支持入场过渡的浏览器使用静态反馈；生图画布保留原有例外。

## 网页收集与反馈

- 网页图片旁只显示一个 32px Reframe logo 入口，保留 40px 透明点击区域，点击后展开「立即逆向」和「加入 Reframe」两条路径；触发器不直接收集，图片右键菜单仍保留两条入口。
- 加入只持久保存参考图并复用已有项目，不弹出面板、不切换当前项目、不调用模型。需已启动并配对连接本机服务，没有离线队列；相同捕获字节去重，服务重启后保留已保存图片。
- 点击立即响应；呼吸点表示保存中，勾号表示加入成功，重复图片提示已存在，失败可重试。成功提示默认显示 4 秒，页面隐藏、鼠标停留或键盘焦点进入提示时暂停倒计时；减少动态效果时改为静态反馈。
- 项目记录新增「全部 / 待逆向」筛选。待逆向为尚未创建逆向任务的项目，服务端在分页前应用筛选；切换时回第一页并清空批量选择，保留搜索能力。零任务项目显示「待逆向」，工作台入口显示「开始逆向」。筛选即时切换，仅指针按压保留短反馈。

更新此功能需在任务结束后重启本机服务、重新加载原扩展目录并刷新已打开网页。无需重新配对，不改变既有项目和图片。

本机服务已在无任务时重启，重启前后 71 个配置、记录和图片文件哈希一致；只读验证真实待逆向筛选接口返回零逆向任务的项目。浏览器工具无法点击 closed Shadow DOM 内的悬浮按钮，因此未完成真实网页点击和跨域捕获的端到端验收；`/collection-preview` 使用示例响应，不执行真实保存。扩展仍需手动重新加载并刷新网页，未调用真实模型，本次仅作本地 Git 提交，不推送或发布。
