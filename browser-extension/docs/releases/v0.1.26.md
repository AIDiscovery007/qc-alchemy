# QC-Reframe v0.1.26 · 工作台操作精简与生成流程梳理

2026-10-02 · 路径选择收进页头，提示词工具回到内容旁，底部主操作随创作阶段切换。

## 本次变化

- **路径选择更紧凑**：四条逆向路径统一使用页头下拉框，各路径保留独立状态。顶部移除重复的任务中心入口，继续从左侧导航进入。
- **提示词工具集中**：Markdown 导出移至提示词框内、复制按钮旁；编辑使用铅笔图标。图标保留悬停说明和可访问名称。任务指令去掉重复的可见标签，输入框仍可直接编辑。
- **一个主操作串起流程**：首次在底部生成提示词，运行中可取消，完成后再选择比例并生成图片。任务指令或多图编排变化后，先更新提示词再生图；上传主体未完成、输入缺失或编辑草稿期间阻止无效操作。
- **重试靠近提示词**：已有提示词时，通过「雕琢提示词」旁的重试图标重新生成；空态时禁用。失败或取消后可再次开始，版本选择和结果抽屉继续保留。
- **保留通用风格的明确选择**：风格路径已有主体图时，输入区仍提供「仅提取通用风格」轻量操作，只使用参考图且不清除主体。通用风格结果生成后，可使用当前主体继续生成专属提示词。

## 升级与安装

从 v0.1.25 升级，本机 bridge、运行技能和依赖没有变化；无需数据迁移、重新配对或因本次界面升级重新验证模型，现有项目、提示词和图片继续保留。

完整仓库升级流程：

1. 等待运行中的任务结束，或在界面取消后，在原 `browser-extension` 目录运行 `npm stop`。
2. 保留本地改动与 `.local/` 数据，将原仓库更新到 `v0.1.26`，运行 `npm run setup`，再运行 `npm start`。重启用于同步服务版本号；管理脚本不会复用版本号不同的旧服务。
3. 重新加载原浏览器扩展；ZIP 安装使用本次 Chrome ZIP。刷新已打开的工作台和网页，使新界面与脚本生效。

若只更新浏览器端，可继续使用 v0.1.25 bridge，无需为本次界面改动重启服务；健康检查仍显示旧服务版本，扩展版本以浏览器扩展管理页为准。从更早版本升级，应按各版本说明更新完整仓库。

首次安装请按 [v0.1.26 安装指引](https://github.com/AIDiscovery007/qc-reframe/blob/v0.1.26/browser-extension/docs/INSTALL_WITH_CODEX.md) 获取完整仓库。**Chrome ZIP 仅包含浏览器端，不包含本机 bridge 和运行 skill，不能单独完成首次安装。**
