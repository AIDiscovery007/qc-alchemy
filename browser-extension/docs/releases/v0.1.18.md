# QC-Reframe v0.1.18 · 新名称与全局 R 标志

<img src="https://raw.githubusercontent.com/AIDiscovery007/qc-reframe/v0.1.18/browser-extension/public/icon/128.png" width="96" height="96" alt="QC-Reframe R 标志" />

- 插件更名为 **QC-Reframe**：同步更新面板、右键菜单、工具栏提示、导出文件名和安装说明。
- 统一采用 Raft 配色的几何 R 标志：工具栏、网页悬浮按钮、面板和文档共用同一源图。
- GitHub 仓库更名为 [AIDiscovery007/qc-reframe](https://github.com/AIDiscovery007/qc-reframe)，浏览器 ZIP 使用新名称。

## 安装与升级

首次安装使用 [README 中的安装 Prompt](https://github.com/AIDiscovery007/qc-reframe/tree/v0.1.18#让-codex-帮你安装)。需要完整仓库中的本机服务；附件 Chrome ZIP 仅包含浏览器端。

已有用户：完成或取消任务 → 在原目录 `npm stop` → 获取 v0.1.18 → `npm run setup` → `npm start` → 重新加载原扩展并刷新网页。配对码、项目记录、图片和插件模型选择沿用，无需重新安装或迁移数据。若仍看到旧名称或图标，先重新加载扩展，再刷新已打开的网页。

本机 Codex CLI 仍需单独保持最新，更新桌面 App 不代表 CLI 已更新；模型可用性以账号权限和实际验证为准。

## 验证

类型检查、生产构建及 60 项测试通过；发布包仅包含浏览器端文件，不含本地图片、Prompt、令牌或配置。
