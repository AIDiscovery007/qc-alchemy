# QC-Reframe v0.1.20 · 创作工作台与生图动效

- 新增宽版创作工作台，保留原有轻量浮层和工具栏弹窗，通过「工作台」按钮进入。提供项目导航、三路径编辑、提示词版本、生成结果画廊、放大和原图对照。
- 新增项目卡片、参考图上传和任务中心，可查看并单独取消并行任务。轻量界面打开工作台时交接当前项目和表单草稿，两种界面共用后台任务与记录。
- 设置中心扩展为 CLI、模型、连接、本地数据四个分区。检测实际 Codex CLI 安装来源与版本，支持已确认来源的独立安装版、npm 和 Homebrew 安装升级；独立版使用原 CLI 的 `codex update`。重新检测显示完成反馈和时间。
- CLI 升级与运行任务、模型验证互斥；升级后刷新模型目录并清除旧模型信任。App 内置和无法确认来源的安装保留原安装方式，不自动覆盖。
- 历史原图对照读取本次生图保存的主体引用，不使用后来替换的图片；完整复刻对照逆向参考图，仍保持纯文生图。
- 工作台生成画布新增像素动效，真实结果读取成功后揭晓一次。去掉生成中的等待文案、白底块、转圈和顶部进度提示条，取消入口收进结果工具栏。历史结果不重播，完成、取消、失败和离开项目后释放动效资源。
- 生图画布始终使用标准动效，不跟随系统“减少动态效果”设置；后台或离屏暂停，WebGL 不可用时显示静态像素。图形引擎按需加载，不进入网页浮层脚本。相关 MIT 许可附于 Chrome ZIP 的 `THIRD_PARTY_NOTICES.txt`。

## 安装与升级

首次安装使用 [README 中的安装 Prompt](https://github.com/AIDiscovery007/qc-reframe/tree/v0.1.20#让-codex-帮你安装)。需要完整仓库中的本机服务和技能；附件 Chrome ZIP 仅包含浏览器端。

已有用户：完成或取消任务 → 在原插件目录 `npm stop` → 备份整个 `.local/` → 获取 v0.1.20 → `npm run setup` → `npm start` → 重新加载原扩展并刷新工作台和网页。请同时更新本机服务与扩展；旧服务缺少新增的原图对照和 CLI 管理端点，混用会导致请求失败。

沿用已有项目、图片和配对信息，无需重新配对。从 v0.1.19 升级无需迁移存储目录；从更旧版本升级仍沿用原有自动迁移流程。本版本增强 CLI 上下文校验，升级后请在设置中心重新验证并使用模型。插件更新不自动执行 CLI 升级，需由用户点击升级按钮。

## 验证与限制

发布 ZIP 构建、TypeScript 检查和 105 项自动测试通过，覆盖消息认证、任务与图片存储、CLI 来源识别与固定升级命令，以及动效引擎与网页脚本的打包隔离。ZIP 内容及 SHA256 校验完成，不包含本地项目、图片、令牌或配置。

开发期间使用明确标注的示例数据验证了工作台、设置、结果画廊、像素等待与揭晓、取消、历史切换、失败及 WebGL 降级。已通过本机服务接口确认历史主体图片可读取，并只读验证独立版 CLI 检测及更新检查。

本次发布未发起真实模型任务或执行 CLI 升级。最后一次取消系统 reduced-motion 联动后，浏览器预览被客户端拦截；该小改动已通过构建、类型检查和自动测试，尚未完成浏览器复验。预览不代表所有已安装浏览器扩展环境均已端到端验收。
