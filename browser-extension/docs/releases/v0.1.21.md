# QC-Reframe v0.1.21 · 多图重演、细节观察与图片预览

2026-10-01 · 相比 v0.1.20，汇总 13 次功能与修复提交。配图来自当前版本的示例预览，使用已公开的画廊素材，未发起新的模型任务。

## 多图重演：把多个主体编排进同一画面

**新增第四条创作路径。** 以一张参考模板组织 2–6 张主体图，逐图指定人物、物品、服饰、场景或细节及需要保留的特征；支持换序、替换、与模板互换，历史对照保留当次完整输入。

![多图重演：大模板、主体编排与用途设置](https://raw.githubusercontent.com/AIDiscovery007/qc-reframe/v0.1.21/browser-extension/docs/releases/v0.1.21-multi.png)

## 图片先调好，再进入创作

**各处缩略图均可点击预览**，支持缩放、拖动和适应窗口；项目、任务和结果缩略图不再叠放遮挡图片的放大图标。仅从准备画面进入的预览支持左右旋转 90°，点击「应用旋转」后，后续逆向和生图使用旋转后的图片；关闭而不应用则保留原图。

![准备画面旋转：应用后用于后续逆向与生图](https://raw.githubusercontent.com/AIDiscovery007/qc-reframe/v0.1.21/browser-extension/docs/releases/v0.1.21-rotation.png)

## 灵感先收集，项目更好整理

网页图片菜单提供「立即逆向 / 加入 Reframe / 打开工作台」，收藏不启动模型。项目库新增待逆向筛选、每页 24 项、全库搜索与按需缩略图。**可批量隐藏项目，小眼睛统一控制项目库、侧栏和任务中心的显示**；隐藏保留历史与图片，也不会取消任务。隐藏和恢复使用靠右的纯图标按钮，保留操作动效。

![项目管理：小眼睛开关、已隐藏标记与右侧恢复图标](https://raw.githubusercontent.com/AIDiscovery007/qc-reframe/v0.1.21/browser-extension/docs/releases/v0.1.21-projects.png)

## 观察更细，操作更顺手

- **Alchemy 先细查再写提示词**：整图定位 → 工具裁切放大与取样 → 核查主体、纹理、边缘和光影 → 回看整图。精简重复指引，保留不可辨细节的不确定性；不承诺固定还原率。
- 主体与参考图一键互换；生图支持预设及自定义宽高比，结果显示真实像素尺寸与比例。比例通过提示词约束，不保证模型精确执行。
- macOS 结果支持直接打开图片、在 Finder 定位，保留复制图片路径。
- 统一按压、复制与处理中反馈，修复网页浮层样式、轻量预览加减图标对齐，以及隐藏项目时并发切换导致的选择丢失。

## 升级与验证

已有用户：任务结束后 `npm stop` → 备份 `.local/` → 获取 v0.1.21 → `npm run setup` → `npm start` → 重新加载原扩展并刷新工作台和网页。**服务与扩展需要一起更新**，沿用项目、图片和配对信息；新增缩略图缓存按需生成，不修改原图。

首次安装请使用 [安装指引](https://github.com/AIDiscovery007/qc-reframe/blob/v0.1.21/browser-extension/docs/INSTALL_WITH_CODEX.md)。Chrome ZIP 仅包含浏览器端，仍需完整仓库中的本机服务和技能。

发布 ZIP 构建、TypeScript 检查及 198 项自动测试通过，ZIP 内容与 SHA256 已核对。界面配图和交互检查使用示例数据；本次未调用真实逆向或生图模型，多图融合效果及还原质量尚未做本版对照实测。网页封闭浮层的完整真实点击流程、触屏手势仍需对应环境验收。
