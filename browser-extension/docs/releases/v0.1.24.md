# QC-Reframe v0.1.24 · 创作工作台与悬窗交互升级

2026-10-02 · 统一创作指令，整理项目与结果展示，让网页悬窗和工作台拥有一致的操作体验。

## 本次变化

- **四条路径共用任务指令**：提取风格、完整复刻、主体重演和多图重演都可编辑任务指令，指令随提示词版本保存。各路径、版本的草稿独立保留；旋转或互换图片继续携带指令。修复通用风格的图号歧义，以及后台刷新切走正在编辑版本的问题。
- **后台会话独立运行**：逆向、生图和模型验证默认使用 Codex 临时会话，减少聊天历史中的后台记录；项目、提示词和图片仍保存在 Reframe。图片检查进度区分整图、局部与失败，并展示图号和目标倍率，改进检查结果的图片展示。
- **项目库新增列表视图**：卡片与列表可切换并记住偏好，保留搜索、筛选、分页及批量选择。项目库、最近项目和任务中心的缩略图统一打开对应项目或提示词版本；详情大图预览与输入图旋转仍可使用。
- **统一等待反馈与动效设置**：工作台在逆向等待、参考图与模板恢复时复用像素效果。设置中心新增「减少动态效果」，支持跟随系统、开启、关闭，并同步到工作台与网页悬窗。保留 WebGL 不可用时的静态回退、后台与离屏暂停及结束清理。
- **进度与取消集中展示**：无提示词结果时，逆向阶段文字和取消入口集中到提示词等待区，减少重复状态。取消请求按任务防重，失败后可重试；已有结果继续保留。
- **结果区采用留白画廊**：去除嵌套底色和重复标签，精简版本、尺寸与缩略图布局，文件操作收为图片外的轻量工具条。原有生图像素动效与完成揭晓保留。
- **网页悬窗对齐工作台**：打开悬窗后仍可浏览网页、收集其他图片，图片入口与菜单自动避让悬窗和通知。图片更换、提示词及排除项编辑、版本切换、原图对照、历史结果、生成信息和文件工具条共用交互。点击或聚焦悬窗会关闭图片菜单，菜单不再抢占输入框的方向键、Home/End 和 Tab。

## 升级与安装

从 v0.1.23 升级需要同时更新本机服务和扩展：

1. 等待运行中的任务结束，或在界面中取消任务，再停止原 bridge。
2. 在保留本地改动和 `.local/` 数据的前提下，将完整仓库更新到 `v0.1.24`，在 `browser-extension` 目录运行 `npm run setup`，然后运行 `npm start` 重启 bridge。
3. 重新加载原浏览器扩展；ZIP 安装使用本次 Chrome ZIP。随后刷新已打开的工作台和网页，使新脚本生效。

本次不新增项目、图片或配对数据迁移，无需重新配对。新增任务指令兼容读取旧记录中的指令字段；原有项目、历史提示词和图片继续保留。从更早版本升级时，已有的存储迁移机制仍按对应版本说明运行。

后台临时会话结束后无法从 Codex 聊天历史恢复，但 Reframe 中的已保存结果仍可访问。此更新不会自动归档既有 Codex 聊天。排障时可显式使用 `ALCHEMY_PERSIST_CODEX_SESSIONS=1 npm start` 保留逆向与生图会话；模型验证始终使用临时会话。

首次安装请按 [v0.1.24 安装指引](https://github.com/AIDiscovery007/qc-reframe/blob/v0.1.24/browser-extension/docs/INSTALL_WITH_CODEX.md) 获取完整仓库。**Chrome ZIP 仅包含浏览器端，不包含本机 bridge 和运行 skill，不能单独完成安装。**
