# 待发布 · 本机图片操作

生成结果区增加「打开图片」与「在文件夹中显示」，覆盖工作台、工具栏弹窗和网页浮层。macOS 分别调用系统默认看图软件和 Finder；定位时选中当前生成图片。保留「复制图片路径」，不重新下载、不复制图片文件。

操作成功后不增加说明文字，按钮名称保持不变；复制路径只保留短暂勾选图标反馈。操作绑定当前选中的任务和生图记录。扩展只传记录 ID 与固定动作，本机服务校验配对、请求来源、完成状态与图片内容后执行；不接受前端提供的路径或命令。历史图片被移走、损坏或系统打开失败时显示错误；其他操作系统暂不支持直接打开，可复制路径。

升级需要重启本机服务、重新加载扩展并刷新网页，不需要重新配对或迁移数据。本功能未发布新版本。

验证：合并后构建、TypeScript 检查与 123 项自动测试通过；覆盖认证、历史记录选择、错误动作、缺失/损坏/符号链接文件和系统执行失败；旧文件迁移后即使内容哈希匹配，打开前仍须通过图片格式检查。工作台与弹窗预览验证了按钮、错误反馈及 390px 窄屏换行。公开画廊样例已在 macOS 默认预览应用中打开，Finder 已选中对应文件。未调用生图模型。

与项目分页及缩略图改动合并后，重新构建、类型检查和全部 123 项测试通过。本机服务在无活跃任务时重启，69 个原有配置、记录和图片文件校验无变化。用户已在实际扩展中看到并点击新按钮；随后精简成功反馈的前端改动已构建，浏览器侧仍需手动重新加载扩展并刷新页面，最新已安装界面的完整点击链路未自动实测。
