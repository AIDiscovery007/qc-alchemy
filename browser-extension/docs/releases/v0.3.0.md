# QC-Reframe v0.3.0 · 作品画廊、完成提醒与对齐双画布

2026-10-03 · 在同一个画廊浏览跨项目作品，在对齐画布中比较输入与结果，任务完成后及时接回创作。

## 作品画廊：按原比例浏览所有生成结果

- **入口位于「全部项目」上方**：汇集所有项目已完成且文件可读取的生成图片，按真实宽高动态分配到较短列，保留横图、竖图和方图的原比例。
- **从浏览回到创作**：支持搜索、项目与图片比例筛选、时间排序和密度切换。点击预览原图及尺寸、模式、提示词版本、生成时间；「查看所在项目」定位到对应模式、版本和生成记录。
- **长列表按需加载**：每页读取 96 条摘要，只挂载视口附近的卡片；缩略图限制并发并使用有上限的缓存，打开预览才读取原图。窗口或密度变化保留阅读位置，数据变化时重新核对分页版本。
- **浏览状态可靠**：默认排除隐藏项目，开启「包含隐藏项目」后显示来源标识。修复延迟分页重新打开已关闭预览的问题；成功显示且前台可见的原图才计为已读。兼容合法旧版生成图片路径，文件缺失或不可读取时不加入画廊。

## 完成提醒：离开面板也能接回结果

逆向和生图完成后，默认显示界面未读标记、扩展徽标和静默桌面通知；设置中心可主动开启短提示音，选择音色、音量并试听。并行完成合并提醒，通知可定位具体结果；当前可见结果自动已读，取消任务和加载历史记录保持静默。

后台通过鉴权任务状态接口同步已持久化结果，支持关闭面板、后台重启及断线后的恢复。隐藏项目不弹出通知或发声；系统通知关闭时仍保留界面提醒。

## 项目管理：隐藏、恢复与跨窗口撤销

- 小眼睛以闭眼/睁眼切换「包含隐藏项目」，指针操作使用短过渡，键盘和减少动态效果即时切换。卡片、列表与详情均可隐藏或恢复项目，进入批量管理后才显示勾选与批量按钮。
- 成功操作可撤销，失败保留选择以便重试。撤销只覆盖服务端本次实际变更的项目，避免重复或并发请求错误恢复其他窗口的操作；查看范围切换后的旧响应不覆盖新打开的项目。
- 操作反馈改为可关闭的浮层：普通成功 4 秒、可撤销反馈 6 秒后消退，悬停、聚焦、页面进入后台及处理中暂停计时；错误保留到关闭。连续操作更新当前反馈，不被旧计时器清除，也不挤动页面。

## 工作台：对齐双画布与一致的页头

输入与结果采用等宽双画布，共享标签、图片、图条和操作区的基线。图片完整居中、不裁切，提示词展开时两侧同步调整；窄屏切换「输入 / 结果」查看单画布。模式、版本、生成历史、画廊定位和查看后已读继续保留，提交等待与取消状态正常接续。

提示词收起后不可交互并归还焦点，Escape 不误关结果。画廊页头与项目库、项目详情共用位置、内边距和标题基线，作品统计移入内容区，滚动时保持页头稳定。

网页图片菜单展开后，移到另一张图片立即收起旧菜单，仅显示新图的 R 按钮；保留同图操作、键盘焦点和减少动态效果支持。

## 升级与安装

从 v0.2.0 升级**无需数据迁移或重新配对**，现有项目、提示词、图片和配置保留。画廊、完成提醒和跨窗口撤销依赖新版 bridge，请更新完整仓库：

1. 等待运行中的任务结束，或在界面取消后，在原 `browser-extension` 目录执行 `npm stop`。
2. 保留本地改动与 `.local/`，将原仓库更新到 `v0.3.0`，执行 `npm run setup`，再执行 `npm start`。健康检查应显示服务版本 `0.3.0`。
3. 重新加载原浏览器扩展；ZIP 安装使用本次 Chrome ZIP，扩展管理页确认 `0.3.0`。刷新已打开的工作台和网页，使新页面与内容脚本生效。
4. 按浏览器要求确认新增权限：`notifications` 用于桌面提醒，`offscreen` 用于可选提示音，`alarms` 用于后台恢复检查。声音默认关闭，可在设置中心主动开启。

首次安装按 [v0.3.0 安装指引](https://github.com/AIDiscovery007/qc-reframe/blob/v0.3.0/browser-extension/docs/INSTALL_WITH_CODEX.md) 获取完整仓库。**Chrome ZIP 仅含浏览器端，不含本机 bridge 和运行 skill，不能单独完成首次安装。** 轻量端未提交草稿属于浏览器会话数据，不保证跨浏览器重启保留，重要编辑请先保存。
