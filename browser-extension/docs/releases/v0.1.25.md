# QC-Reframe v0.1.25 · 按需结果抽屉与工作台体验优化

2026-10-02 · 生成结果按需推出，编辑空间随操作调整；保留原有像素等待、图片揭晓和图片预览体验。

## 本次变化

- **结果改为推挤式抽屉**：没有内容时隐藏，提交生图即从右侧推出并收窄编辑区。主动收起不会取消任务，完成后以「新结果」入口提醒，不打断当前编辑；开合状态按项目、路径和提示词版本分别保留。图片区域去掉底板、重复标题和张数，底部保留浅色纯图标工具条。
- **等待与揭晓连续衔接**：请求尚未回包时也有像素等待和提交状态，切换项目再返回可恢复等待，避免重复提交；失败可重试并保留已有图片，取消后可返回历史结果。继续使用原有生成动效和图片预览，保留缩放、拖拽、原图对照及文件操作。
- **项目栏支持展开和收起**：通过顶部图标切换，收起后保留导航和项目缩略图，悬停可查看名称。侧栏与结果抽屉独立控制；窄屏默认收起侧栏，结果抽屉使用剩余工作区，键盘及减少动态效果时即时切换。
- **准备画面更简洁**：四条路径的主预览采用等高区域，按原比例完整显示图片，移除衬底和外层圆角。双图互换按钮位于两图之间，更换主体入口移至标签行，放大入口贴近图片；过窄时上下排列，保留可读标签与操作入口。
- **弹窗支持点击蒙板关闭**：新建项目、设置、任务中心、删除确认、生成信息和图片预览统一支持；点击内部空白或从内部向外拖拽不误关，保留忙碌保护、叠层及焦点恢复。修复任务中心内部空白误关闭的问题。
- **帮助按需展开**：精简零任务数量、重复状态、无内容排除项及单页翻页控件。动效与通用风格说明可悬停查看或点击、键盘展开；安装路径、检查时间与升级命令收纳到详情，未连接时仍展开配对帮助。必要标签、错误、进度、费用和删除后果继续可见。

## 升级与安装

从 v0.1.24 升级，本机 bridge、运行技能和依赖没有变化；无需数据迁移、重新配对或因本次界面升级重新验证模型，现有项目、提示词和图片继续保留。

完整仓库升级流程：

1. 等待运行中的任务结束，或在界面取消后，在原 `browser-extension` 目录运行 `npm stop`。
2. 保留本地改动与 `.local/` 数据，将原仓库更新到 `v0.1.25`，运行 `npm run setup`，再运行 `npm start`。重启用于同步服务版本号；管理脚本不会复用版本号不同的旧服务。
3. 重新加载原浏览器扩展；ZIP 安装使用本次 Chrome ZIP。刷新已打开的工作台和网页，使新界面与脚本生效。

若只更新浏览器端，可继续使用 v0.1.24 bridge，无需为本次界面改动重启服务；健康检查仍显示旧服务版本，扩展版本以浏览器扩展管理页为准。从更早版本升级，应按各版本说明更新完整仓库。

首次安装请按 [v0.1.25 安装指引](https://github.com/AIDiscovery007/qc-reframe/blob/v0.1.25/browser-extension/docs/INSTALL_WITH_CODEX.md) 获取完整仓库。**Chrome ZIP 仅包含浏览器端，不包含本机 bridge 和运行 skill，不能单独完成首次安装。**
