# 颜色取证：重要性、语义区域与像素依据

仅在颜色影响生成决策、需要选择代表色或复核色差时读取。观察动作和完成条件统一见 [Observation](workflow.md)；取色不能代替查看局部。

## 选什么，为什么取

综合覆盖面积、焦点、相邻对比和辨识度选择颜色角色。先区分偏差来自色相、饱和度、明度、覆盖范围，还是反射/透射与照明解释；次要区域通常不需要色号。

- **重要且可分离**：可读取原像素时主动采样，绑定区域、角色和覆盖范围。
- **重要但混色**：先分开中间调、局部染色、反光或透见背景；渐变保留色带与空间关系，不压成一个平均色。
- **取色依据不足**：保留可见的颜色关系与范围，说明限制，不能因此省略关键颜色角色。

同一区域可能包含多个决定效果的色层；一个“脸部/金属”中位色不能代表全部。主色、高光和阴影也不是必须填满的三色配额。材料本色和光源不能仅凭像素唯一反推。

## 怎样测

内置 `alchemy_inspect_image` 可用 `sample: true` 加 `bbox` 返回未缩放 ROI 的 sRGB 通道中位数与范围；区域最多 100 万原像素。工具会排除全透明像素，部分透明 RGB 未与背景合成，不能直接当作可见显示色。返回值不证明语义代表性，仍须按下列步骤核查。

1. 优先源文件，读取 ICC；无配置时查已知来源，仍未知可按 sRGB 解释但须标注假设。使用实际色彩转换，不能仅改配置标签。保留原件；仅处理分析副本或内存。
2. 统一到明确的比较空间。提示词 HEX 用 sRGB，记录输入配置、转换工具与设置；工具未暴露的条件标为未知。广色域映射可能裁切，映射色不能称为无损原色。
3. 按语义与受光角色选矩形或蒙版，排除无关边界、文字、其他物体和独立反光。透明区域须说明透见背景的作用。统计用未缩放像素，透明像素不能忽略 alpha 直接当显示色。
4. 均匀区域可用 RGB 各通道中位数减轻孤立点影响；它不一定是某个真实像素。混色、多峰区域分区或报告范围，不能机械平均。需要实际像素颜色时注明选点方法。
5. 在同一语义角色内轻移/缩放框核对稳定性，不能跨到另一个色层凑稳定样本。回看取样框，数值稳定不等于区域有代表性。

最小记录：输入文件/版本、方向与尺寸、ROI 与语义角色、配置或假设、输出空间与转换条件、统计方法、代表值和已知限制。工具未测的项目明确未测，不生成置信百分比。

## 怎样用与复核

只把必要代表色写入对应区域，同时写覆盖范围、相邻对比与材料响应；不整表复制样本。重要颜色无法用单值表达时，明确色层分布及过渡。先删除冲突旧色彩/光照句，再补新描述。

参考与结果重新定位对应语义区域；同一坐标或尺寸不是自动配准。先看整图的色块面积与明暗，再看局部颜色。RGB/HSV 可解释方向，低饱和或近黑的色相读数可能无意义；不能换算整幅相似率。

需要感知色差时才用 Lab/ΔE，明确空间、白点、转换及公式。针对原参考和针对有损映射后目标的比较分开；单个色差值不能覆盖构图、材质、面积，也无跨题材通用的通过阈值。
