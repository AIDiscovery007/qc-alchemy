# 从观察到可执行提示词

先通过 [Observation 验收](workflow.md)，再筛选和压缩；交付篇幅与分析深度分开。用户指定的语言、格式、原样提交要求优先，不固定生成平台参数。

## 统一骨架

按以下顺序组织，省略无关字段；短任务可合并自然段，整体情绪专段与适用的人物专段按下文独立保留：

1. **任务与输入职责**：还原、配方、重演、锁定结构或纠偏；各实际输入提供什么。
2. **内容与结构**：主体、数量、状态、文字、用户保留项；视角、位置/比例、裁切、留白、前后层次。
3. **分区域表现**：颜色角色与覆盖、明暗过渡、高光形状、媒介、纹理的形态/尺度/方向/强弱。
4. **关键关系**：接触、遮挡、透明/反射、轮廓形成方式、表面和背景如何衔接。
5. **防错与规格**：仅列当前图容易发生的误解，以及用户需要的比例、文字、背景等。

内容与结构之后写整体情绪专段，再接适用的人物专段；后续分区域表现与这些情绪成因保持一致。

每个重要观察都有去向：写成区域指令，因用户限制转译/省略，或因证据不足改为有依据的范围。不能用“严格参考原图、细腻质感、95%还原”替代控制点，也不把坐标、工具轨迹和完整测量报告塞进 prompt。

## 按模式分配内容

| 模式 | 应写入的内容 |
|---|---|
| 具体复刻 | 具体主体、状态和构图。未确定生成时带图，写成独立文本；纯文生图不得依赖“如图” |
| 通用风格 | `[SUBJECT]` 等用户需要的变量，加稳定的空间/色彩/媒介关系与适配条件；不能锁死原物体清单，也不能泛化成风格标签 |
| 模板重演 | 实际输入职责 → 选定身份线索 → 模板构图/姿态 → 明暗与可见度 → 焦点载体 → 材料细节；按 [重演规则](template-reconstruction.md) 转译兼容性 |
| 保留结构换画法 | 输入职责与迁移范围 → 锁定的内容、几何及空间关系 → 各已有区域的画法和交界；结构不变不自动锁定所有颜色/光照 |
| 定点纠偏 | 偏差所在区域、目标表现与须保留项；替换冲突原句，不在末尾累加相反命令 |

多图编号与实际提交顺序一致，没有提交的图不能引用。专属提示词展开变量，不留下 `[SUBJECT]`。一个输入可承担多种职责，文字也可提供目标主体；不预设“图 1 永远是人物”。

## 整体情绪专段

四条逆向路径（含仅提取通用风格）均在最终 `promptZh` 与 `promptEn` 正文中用空行分出 **整体情绪与氛围 / Overall mood & atmosphere** 段落，人物、物体或无人画面都要输出；与人物微表情专段分开，不因目标无人而省略。按 [整体情绪观察](domain-adaptation.md#整体情绪与氛围所有题材) 写明主要情绪、表达强弱、有依据的次级情绪/反差，以及承载它们的具体视觉关系。观察摘要可概括感受与依据，但不能代替生成正文；用户另定格式时仍保留这些内容。

将解读改写成可执行目标，例如“整体呈现克制的疏离感，以主体较小的画面占比、周围连续留白和冷硬侧光维持距离感”，仅在当前证据与任务范围支持时使用这些控制点。不只写“高级、治愈、有故事感”，也不以新增人物、道具、天气或事件解释情绪。表达平实的图仍写其低情绪强度及客观呈现方式；不要为凑段落强加戏剧性。

| 路径 | 情绪来源与迁移边界 |
|---|---|
| 完整复刻 | 展开参考图整体感受及人物/物体与环境共同形成它的具体关系，纯文字即可执行 |
| 提取风格（双图） | 保留主体图的表情、动作、几何、构图和内容关系；只用参考图允许迁移的色光、笔触、边缘和表面画法表达可兼容的氛围。参考情绪依赖被锁定的结构时不强行照搬，在限制中说明；正文描述兼容后的目标情绪，不能同时要求相反感受 |
| 仅提取通用风格 | 抽象参考图稳定的情绪基调与形成机制及适用条件，主体保持变量，不锁定原人物、物体清单或虚构缺失主体 |
| 主体重演 | 模板提供整体情绪与允许重演的视觉关系，主体图提供身份；按用户锁定项适配表达强度与机制 |
| 多图重演 | 模板统摄整幅氛围，各输入按职责参与，保留有依据的角色差异与情绪反差；不把所有来源的情绪叠加，也不强迫所有角色同一表情 |

用户指定的情绪目标及保留项优先于默认来源；先协调冲突，再写一个自洽的生成目标。中英文保持相同的情绪方向、强弱、层次与成因，不能把“略带不安”翻成强烈恐惧。局部微表情与整体氛围可以有反差，但须说明这种关系，不能用整体情绪覆盖已锁定的微动作或补造隐藏面部。

## 人物专段

最终画面包含人物且有相关可见证据时，在内容与整体姿态之后单独写一段 **人物神态与微动作**；中英文输出分别在 `promptZh` 与 `promptEn` 正文内保留对应段落，用空行隔开，英文可标为 **Expression & subtle gestures**。这段属于直接用于生成的提示词，不能只放进 observations、附注或排除项，也不能以“严格参考表情”代替实际描述。用户明确另定格式时遵从用户要求，仍保留相关控制点。

按 [人物细查](domain-adaptation.md#人物微表情微动作与神态含绘画人物) 的证据，将视线目标与眼睑/眉眼、嘴角/唇缝/下颌、头颈肩的微小偏转、手指与接触、动作引起的衣褶或遮挡连成自然段；写清部位、方向、幅度、松紧及相互关系，只展开当前可见且影响结果的项。神态词是这些线索共同形成的观感，不替代它们。保留细小不对称与克制幅度，不为了“生动”加深笑容、瞪大眼睛或强化动作。多人逐一绑定身份/画面位置与互动对象，避免串用表情。

专段的来源随任务分配：

| 路径 | 人物细节来源与写法 |
|---|---|
| 完整复刻 | 参考图的具体神态与动作；用脱离图片仍可执行的文字展开，不能写“同参考图” |
| 提取风格（双图） | 默认保留主体图的表情、视线与微动作；参考图只提供这些区域的画法，不以参考人物的神态覆盖主体 |
| 仅提取通用风格 | 有人物参考时写“人物适用时”的条件段，提炼眉眼、唇线、姿态张力等如何被画法表达；具体表情、动作与身份留给目标主体，不锁死参考人物，也不虚构缺失主体 |
| 主体重演 | 主体图提供身份，模板提供可迁移的神态、微表情与微动作；按新身份和视角重建，不粘贴源脸投影 |
| 多图重演 | 按每图职责分别确定人物身份，再映射模板中的角色、神态、动作与互动；物品/服饰图不提供人物表情，角色无法对应时说明限制 |

用户明确锁定或更改某项时覆盖对应默认来源，并删除冲突句。目标无人时省略人物段，不因模板有人而添加人物；动物/非人角色按其可见结构适配。面部按部位判断可辨性：保留能确认的眼睑、视线、嘴角等可见线索，仅省略被遮或低清不可辨的部位，不推断隐藏形态；整脸不可辨时才转写可见头肩、体态与遮挡。重要缺口放入 uncertainties，生成正文保留应有的遮挡与可见度。两种语言须保留相同的方向、幅度、接触及否定约束。

## 写具体，但不夸大

将控制点就近绑定区域与关系，例如：

```text
[区域]以[颜色/色层分布]建立[明暗过渡与高光形态]，
叠加[纹理形态、相对尺度、方向、强弱]，覆盖[范围]并在[边界]衔接。
```

仅填写当前图有依据且影响结果的部分。无可辨微纹理时写可见光滑度与光照响应，不补毛孔、裂纹或织纹。混合媒介分区，不能用一个全局颗粒词替代各表面的不同表现。

必要时加入经 [颜色取证](color-matching.md) 核验的 sRGB 代表色；色号仍需绑定作用区域与覆盖范围，不能替代红晕、渐变、透射或反光的分布。

姿态写支撑、躯干朝向、头相对胸廓的转向、关键接触与视线目标；身份特征随新视角重新表现，不把源图头部投影直接接上模板身体。细节分析用于决定这些关系，不整段复制骨架清单。

精确可读文字逐字列出；不可读时说明缺失或保留用户需要的文本变量，不猜字或字体名。输出位图不能冒充精确矢量、字体或可编辑排版。

## 提交前只检查实际词

- 关键控制点及其区域、分布、关系是否还在？压缩掉重复形容词，不压掉区别相近材质/画法的证据。
- 锁定项是否来自用户？是否混入旧姿态、旧光照、全局纹理等互斥句？改原句，不依靠最后一句“优先”抵消。
- 描述尺度是否符合整图？局部细纹没有夸成全幅粗纹，小高光没有扩成大色块。
- 人物专段是否落入实际生成正文？来源、注视目标、微小幅度、接触与遮挡是否一致，是否只剩情绪标签或在翻译中丢失？
- 整体情绪段是否覆盖当前题材并写清基调、强弱、层次与可见成因？是否误把局部表情等同整图情绪、给普通物体添加心理/五官，或为强化氛围越过结构锁定项？
- 防错是否有本图依据？参考图有描线、文字、硬影就不能套“无描线、无字、柔光”等通用禁词。
- 批量任务是否逐条适配了字段与区域？共享骨架不能代替逐图观察；每条脱离批次说明仍可使用。

默认先交付最终提示词，复杂任务附少量关键锚点与限制。若输出格式限定 observations 为 3–6 条，那是充分观察后的摘要；未写进摘要的关键细节仍须落实到提示词。中英文输出时保留同一组约束，不借翻译删除细节。
