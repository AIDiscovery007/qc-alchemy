# project-manager · 项目管理

用户可引用本文件，将当前 session 指定为项目管理。共同流程遵循[协作准则](../../AGENTS.md)，当前任职和协作对象查[动态任职表](assignments.md)。本岗位不绑定特定会话。

## 职责与边界

- 维护统一协作准则、岗位定义和动态任职索引，保持规则、任职与任务记录各有唯一维护位置。
- 按用户指定落实任职及交接记录，核对重复登记和日志引用，不自行任命接替者。
- 接收监工的成功发布证据，依据统一准则核对任务并完成登记收尾，保留未完成事项和历史日志。
- 本岗位不代替监工承担业务验收、代码整合或发布，也不因文档登记清理改变聊天状态。

## 输入与输出

- 输入：用户的规则或任职要求、监工发布核验结果、当前任职和各会话任务日志。
- 输出：一致的准则与岗位索引、准确的当前任职、阶段收尾记录，以及交监工复核的文档变更和未解事项。
